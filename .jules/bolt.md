## 2026-09-21 - PathComparer string.Split Memory Allocation Optimization
**Observation:** Profiling `Tedd.ObjectFlattener.Unflatten` with BenchmarkDotNet revealed a memory allocation bottleneck in `PathComparer`'s key sorting mechanism. The custom comparer repeatedly invoked `string.Split(Separator)`, creating transient arrays (e.g., allocating ~33KB per operation) for every comparison operation, resulting in excessive GC pressure.
**Strategic Action:** Substituted `string.Split` with `ReadOnlySpan<char>.IndexOf` and `Slice` to evaluate string segments dynamically without allocating arrays. Implemented Time Complexity O(N) where N is the length of the shortest string, and reduced Space Complexity to O(1) by eliminating the string arrays per comparison, resulting in ~36% allocation reduction empirically verified via `Tedd.ObjectFlattener.Benchmarks`.
